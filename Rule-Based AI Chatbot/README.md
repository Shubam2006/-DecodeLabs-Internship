# Rule-Based AI Chatbot

## About Project

This is a simple chatbot made using Python. It responds to some predefined user inputs using if-else statements.

## Features

* Responds to greetings
* Tells date and time
* Answers basic questions
* Exits when user types bye

## Technologies Used

* Python
* Datetime Module

## How to Run

Run the following command:

python chatbot.py

## Example

You: hello

Bot: Hello! Nice to meet you.

You: time

Bot: 10:30:45

You: bye

Bot: Goodbye!
